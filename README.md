# DMIT 支付方式：支付宝、PayPal、信用卡、稳定币怎么选，附退款手续费与自动续费注意点

买海外 VPS 时卡住很多人的不是选配置，而是付款那一步。没有双币信用卡、不确定支付宝能不能用、退款会不会被扣掉一笔手续费，这些问题通常在点下"结账"之前才浮出来。DMIT 在国内用户里知名度不低，很大一部分原因就是它的支付渠道对国内用户相对友好，所以这篇把它的付款方式逐条拆开讲清楚。

先说结论：DMIT 目前公开可确认的支付渠道包括支付宝、PayPal、信用卡（走 Stripe）以及稳定币加密货币。支付宝和 PayPal 是最常用的两个，信用卡系统近期做过一次大的安全升级，加密货币是新增的通道，用之前有几件事需要知道。

## DMIT 现在支持的支付方式

下面这几类是能在 DMIT 公开页面和账单流程里确认的：

- **支付宝（Alipay）**：人民币直接付，不用折腾外币卡，实时到账。DMIT 的官方退款说明里专门提到"Alipay（支付宝）由于退款时会返还手续费，因此不收取手续费"，等于官方承认支付宝是主力渠道之一。
- **PayPal**：国际通用，适合有 PayPal 余额或者不想把卡直接交给商家的用户。退款走原路时会被支付商扣手续费。
- **信用卡**：现在已经全面转向符合 PCI 标准的新 Stripe 网关，除了 Visa / MasterCard 这类常规卡，还支持 Apple Pay、Google Pay 和 Cash App。
- **加密货币**：支持 USDC、USDP、USDG 三种稳定币，链路为 Ethereum、Polygon、Base。

关于**微信支付**：一批第三方测评文章和整理帖把它列为可用渠道，但在 DMIT 官方可查的支付说明里，能明确确认的是支付宝、PayPal、信用卡和 Crypto 这几类。差异可能来自结账页在不同时间、不同账单金额下展示的选项不同。稳妥的做法是进结账页看实际列出的按钮，那才是当下真实可用的。

## 结账流程大概是什么样

DMIT 用的还是 WHMCS 那套购物流程，整个路径不复杂：

1. 在套餐页选好机房和线路，加入购物车；
2. 填写账户信息。这里建议用真实邮箱，后续的账单、续费提醒、支付异常通知都走这个邮箱；
3. 到结算页选择支付方式。信用卡相关的选项现在统一叫 **"Credit Card & Others"**，点进去之后会跳转到 Stripe 的页面填写卡信息或选择替代支付方式；
4. 完成支付，实例一般会在几分钟内交付。

有个细节值得提前知道：**所有支付跳转都发生在 Stripe 的安全环境里**，DMIT 自己的页面不碰你的卡号。这也是他们做那次升级的核心目的。

## 信用卡升级之后，老用户要注意什么

这条对已经在 DMIT 有机器的人特别重要。DMIT 在运维日志里说明，为了实施符合 PCI 标准的新 Stripe 网关，他们把所有先前存储在 Stripe 的支付方式以及 WHMCS 内保存的卡基本信息都删掉了，同时清掉了数据库备份和 MySQL Binlog——官方强调从未存储过卡的敏感信息，删除动作属于架构切换的一部分。

带来两个直接影响：

- **旧的卡片管理页面已经不能用了**，需要在新的界面重新添加支付方式。入口是登录后进入"账务"部分，选择"管理信用卡"选项卡，也可以走 `index.php?m=stripe_next_cards` 这个页面。
- **过去设置的信用卡自动续费已经失效**。如果不重新通过 Stripe 添加卡片信息，续费会中断。快到账单日的机器，最好提前去确认一下。

自动续费失效这件事容易被忽略，尤其是季付、年付的机器，等到服务被暂停才发现就有点麻烦。

## 退款会扣多少手续费

DMIT 的退款政策本身写得比较清楚，核心是两档：

- **全额退款**：购买不超过 3 天，且虚拟机使用的流量不超过 30GB；
- **部分退款**：购买不超过 30 天，退款金额按实际支付金额计算，如果按已用流量算出来的价值更高，就按剩余流量退，否则按剩余服务时间退。

退款有两个去向，费用差别很大：

- **退到 DMIT 账户余额**：不收手续费，钱直接变成账户 credit，可以拿来买新机器或者续费；
- **退到原始支付方式**：会扣除支付提供商收取的手续费。支付宝是例外，官方明确说退款时手续费会返还，因此不收。

处理时效方面，官方说法是通常在 48 小时内处理，高峰期会延迟。另外一点跟钱无关但很重要：**发起退款后实例会被关闭**，确认退款后实例和数据会被删除，且不可恢复。要退就先备份。

不予退款的情况也列得挺细，包括对同一系列产品已经退过 3 次、遭受 DDoS 攻击、以"网络状况不佳"或"IP 地理位置原因"为由申请、违反服务条款后单方面向支付公司发起争议等。这些条款在动手买之前扫一眼，比出事之后再翻要划算。

## 付了钱但机器没到，可能是什么情况

偶尔会有用户反馈付款之后机器没自动交付。有论坛帖描述了这么一次经历：用 USDC 付款成功但没拿到机器，发工单后等待时间比官方承诺的更长，提交转账凭证也没有被直接采纳，最后发现账单那边实际记录的是 Alipay 付款、却被标成了加密货币。这类案例说明的是**链上支付和第三方支付渠道的凭据对账本身就容易卡壳**，官方判断依据是支付服务商侧的数据，而不是用户手里的转账截图。

如果你遇到类似情况，几件事能帮你少折腾：保持订单号和支付流水号，工单里一次性把这两样都给全，并且优先检查账单页显示的支付方式是否和你实际操作的一致。

## 付款时绕不开的几个实际问题

**用什么货币结算？** DMIT 的套餐以美元计价，支付宝付款时会自动换算成人民币，你看到的人民币金额就是实际扣款金额。

**一定要有外币卡吗？** 不。这也是 DMIT 在国内用户里口碑不错的原因之一，支付宝和 PayPal 覆盖了大多数需求场景。

**能只用余额付款吗？** 可以，账户 credit 能直接抵扣订单。但要注意，用余额支付的发票退款时只能退回余额，不会再退回原路。

**自动续费稳不稳？** 信用卡自动续费在这轮 Stripe 升级后需要重新绑定。如果你不想折腾自动续费，可以手动续费，或者提前把余额充进去。

**有优惠吗？** 第三方整理提到过洛杉矶 Pro 系列部分套餐的年付折扣，比如特定入门款年付 75 折、其他套餐年付约 9 折，且标注"无需优惠码"。这类阶梯折扣会随活动和库存调整，结账时购物车实际计算出的价格才是准的，别把测评文章里的数字当成固定价。

## 支付方式怎么选，看你的场景

没有外币卡、只想尽快把机器开起来，**支付宝**是最短路径。人民币直付、实时到账，退款到原路还不收手续费，这几条凑在一起，是国内用户最省心的组合。

习惯用 **PayPal** 的人多半是看重它的买家保护机制，代价是退款回原路时要被扣一笔手续费，以及退款到账会慢一些。

需要**自动续费**的话只能走信用卡或 Stripe 支持的替代支付方式，但记得升级后要重新绑定卡片，旧的自动续费设置已经失效了。

有稳定币、想避开传统支付通道的，可以试 **Crypto**，走链上前一定要自己核对到账链路和网络，支付提供商收的付款手续费在退款时不会退回。

不管选哪一种，流程上的建议是一样的：**先用小额月付试一台**，确认线路延迟、晚高峰表现和 IP 质量都符合预期，再转年付。DMIT 的 3 天内全额退款给了这个试错窗口，30GB 流量上限也不算苛刻，但如果用的是按流量计费的场景，试机期间最好别急着跑大流量任务。

至于哪种付款方式本身更"划算"，其实差别不大——DMIT 没有对不同支付渠道设置不同的套餐价格，真正影响你钱包的是选哪档线路、按什么周期付。想比较具体配置和当前价格：
